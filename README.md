# Paradise Nursery

Paradise Nursery is an online plant shop built with React and Redux Toolkit.
Users can browse houseplants by category, add them to a shopping cart,
change quantities, and see the total cost.

## Features
- Landing page with a "Get Started" button
- Product listing grouped by category
- Shopping cart with quantity controls and total cost
- Checkout button (coming soon)

## Tech Stack
- React
- Redux Toolkit
- Vite
